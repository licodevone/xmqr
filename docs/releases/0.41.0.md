# XMQR broker/admin legado 0.41.0 — WSS mTLS remoto explícito (candidato experimental)

P214 permite `MQTT_WSS_BIND` fora de loopback apenas com `MQTT_WSS_REMOTE_ENABLED=true` (ou campos TOML equivalentes) em `secure-mtls`. Certificado cliente, credenciais MQTT, ACL, quota, router e rotação TLS compartilham a política do TCP seguro. Acesso de navegador com `Origin` continua recusado. O client C117/0.34.0 é o par previsto. [Aceite funcional P214](../../prompts/registros/P214-remote-wss-mtls-bind.md).

Estado durável v15 sem migração. O broker 0.40.0 lê v15, mas não oferece WSS remoto; preservar backup privado antes de downgrade. Admin independente 0.10.0 permanece. Distribuição Ubuntu 26.04 amd64, imagem e release somente após gates P215. Fases globais 6A–6D/7–9 e Ubuntu 24.04/arm64/Windows nativo seguem abertas.
