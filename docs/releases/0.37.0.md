# XMQR broker 0.37.0 — cabeçalhos MQTT 5 reservados (experimental)

P203 responde DISCONNECT `0x81` ao tipo de controle zero após CONNACK. P204 responde `0x81` a AUTH com bits reservados não zero. P205 corrige P178: PINGREQ/DISCONNECT com bits reservados não zero passam a responder `0x81`; a 0.36.0 publicada ainda responde `0x82` nesses casos. A matriz MQTT 5 integral continua aberta.

**Estado e rollback:** documento v15 sem migração. Broker 0.36.0 e admin independente 0.10.0 continuam capazes de ler v15; preserve backup privado antes de downgrade. Broker 0.28.0 ou anterior requer backup v14 anterior à migração. O client independente 0.30.0 permanece. Esta versão não é homologação de produção.

**Distribuição publicada:** [prerelease v0.37.0](https://github.com/licodevone/xmqr/releases/tag/v0.37.0), CI da fonte exata, pacote Ubuntu 26.04 amd64, upgrade/rollback descartável e imagens broker/admin legado por digest passaram. Os oito anexos tiveram tamanho e SHA-256 remotos conferidos no [registro P206](../../prompts/registros/P206-release-0.37.0.md). O WSL instalado do operador não foi alterado. Ubuntu 24.04, arm64, Windows nativo e fases globais 6A–6D/7–9 continuam abertos.
