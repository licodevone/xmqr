# XMQR broker/admin legado 0.39.0 — WebSocket MQTT de laboratório (candidato)

P210 adiciona listener WebSocket MQTT opt-in `MQTT_WS_BIND` ou `broker.ws_bind` somente em IP loopback, porta distinta do TCP e perfil `open-lab`. O caminho é `/mqtt` e o subprotocolo obrigatório é `mqtt`. Pacotes MQTT 3.1.1/5 entram no mesmo router e compartilham `MQTT_MAX_CONNECTIONS` e o shutdown com TCP. `Origin` é recusado: este recorte atende CLI local, sem navegador. WSS, TLS/mTLS, autorização de origem e listener remoto dependem de entregas próprias; fase 7 global aberta.

**Estado e rollback:** documento v15 sem migração. Broker 0.38.0 e admin independente 0.10.0 continuam capazes de ler v15; preserve backup privado antes de downgrade. Broker 0.28.0 ou anterior requer backup v14 anterior à migração. Client 0.32.0 é candidato para o transporte WS correspondente; client publicado 0.31.0 não o contém.

**Distribuição:** P211 exige CI da fonte exata, pacote Ubuntu 26.04 amd64, upgrade/rollback descartável, imagens broker/admin legado por digest, tag e prerelease com oito anexos e hashes remotos. Registrar os resultados antes de considerar este candidato publicado. O WSL instalado do operador não é alterado; Ubuntu 24.04, arm64 e Windows nativo ainda não estão homologados.
