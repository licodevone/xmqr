# XMQR broker/admin legado 0.39.0 — WebSocket MQTT de laboratório (experimental)

P210 adiciona listener WebSocket MQTT opt-in `MQTT_WS_BIND` ou `broker.ws_bind` somente em IP loopback, porta distinta do TCP e perfil `open-lab`. O caminho é `/mqtt` e o subprotocolo obrigatório é `mqtt`. Pacotes MQTT 3.1.1/5 entram no mesmo router e compartilham `MQTT_MAX_CONNECTIONS` e o shutdown com TCP. `Origin` é recusado: este recorte atende CLI local, sem navegador. WSS, TLS/mTLS, autorização de origem e listener remoto dependem de entregas próprias; fase 7 global aberta.

**Estado e rollback:** documento v15 sem migração. Broker 0.38.0 e admin independente 0.10.0 continuam capazes de ler v15; preserve backup privado antes de downgrade. Broker 0.28.0 ou anterior requer backup v14 anterior à migração. Client 0.32.0 distribui o transporte WS correspondente.

**Distribuição publicada:** [prerelease v0.39.0](https://github.com/licodevone/xmqr/releases/tag/v0.39.0), CI da fonte exata, pacote Ubuntu 26.04 amd64, upgrade/rollback descartável e imagens broker/admin por digest passaram. Os oito anexos tiveram tamanho e SHA-256 remotos conferidos no [registro P211](../../prompts/registros/P211-release-0.39.0.md). O WSL instalado do operador não foi alterado. Ubuntu 24.04, arm64, Windows nativo e fases globais 6A–6D/7–9 continuam abertos.
