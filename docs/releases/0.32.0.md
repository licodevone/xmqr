# XMQR broker 0.32.0 — diagnósticos de encerramento MQTT 5 (experimental)

P174 aceita motivos de erro permitidos no DISCONNECT do client e publica o Will. P175–P178 enviam motivos selecionados do broker após CONNACK MQTT 5: `0x95` para pacote acima do teto, `0x94` para Topic Alias inválido, `0x81` para Remaining Length com quatro bytes de continuação e `0x82` para flags reservadas em PINGREQ/DISCONNECT. MQTT 3.1.1 continua fechando sem DISCONNECT MQTT 5 nesses cenários. Os testes cobrem limites, ausência de publicação inválida e Will; a matriz normativa completa continua pendente.

**Estado e rollback:** o documento permanece v15, sem migração. Broker 0.31.0 e admin independente 0.10.0 leem v15; preservar backup privado antes de downgrade. Voltar a 0.28.0 ou anterior requer backup v14 anterior à migração. Client independente 0.27.0 permanece parceiro. Fases 6A–6D e 7–9 ainda abertas.

**Distribuição:** [prerelease v0.32.0](https://github.com/licodevone/xmqr/releases/tag/v0.32.0) publicada após [CI do commit exato](https://github.com/licodevone/xmqr/actions/runs/39027534502), pacote Ubuntu 26.04 amd64, ciclo descartável de upgrade/rollback e imagens numeradas executadas por digest. Os 8 anexos tiveram tamanho e SHA-256 remotos conferidos; [P179](../../prompts/registros/P179-release-0.32.0.md) registra hashes e digests. WSL do operador e Docker `latest` permaneceram intactos. Ubuntu 24.04, arm64 e Windows nativo ainda não homologados.
