# XMQR broker 0.30.0 — Client Identifier atribuído (experimental)

P166 aceita CONNECT MQTT 5 com Client Identifier vazio, atribui ID exclusivo de 37 bytes e inclui a propriedade obrigatória `0x12` no CONNACK. O broker recusa antes do commit quando Maximum Packet Size anunciado não comporta a resposta. MQTT 3.1.1 mantém a recusa de ID vazio. O client 0.27.0/C97–C99 pede o ID, permite criar sessão durável e reconecta manualmente; não guarda estado QoS local.

**Estado e rollback:** o documento permanece v15, sem migração nesta versão. Broker 0.29.0 lê v15; preserve backup privado antes de downgrade. Admin independente 0.10.0/A19 permanece compatível com v15. Para voltar ao broker 0.28.0, o backup v14 anterior à migração ainda é obrigatório.

**Distribuição:** candidato sujeito à CI do commit exato, pacote Ubuntu 26.04 amd64, ciclo descartável de upgrade/rollback, imagens numeradas, tag anotada, prerelease e conferência remota de hashes. Não há homologação Ubuntu 24.04, arm64 ou Windows nativo. Fases 6A–6D e 7–9 continuam abertas.
