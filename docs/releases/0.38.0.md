# XMQR broker 0.38.0 — flags fixas MQTT 5 adicionais (experimental)

P207 responde CONNACK `0x81` a CONNECT inicial com bits reservados não zero quando o prefixo comprova MQTT 5 e o Maximum Packet Size permite cinco bytes. Caso contrário, fecha sem inferir versão. P208 responde DISCONNECT `0x81` a PUBACK/PUBREC/PUBCOMP com bits reservados não zero, antes de interpretar o corpo. MQTT 3.1.1 e cabeçalhos válidos preservados. A matriz MQTT 5 integral continua aberta.

**Estado e rollback:** documento v15 sem migração. Broker 0.37.0 e admin independente 0.10.0 continuam capazes de ler v15; preserve backup privado antes de downgrade. Broker 0.28.0 ou anterior requer backup v14 anterior à migração. Client independente 0.31.0 permanece. Esta versão não é homologação de produção.

**Distribuição candidata:** CI da fonte exata, pacote Ubuntu 26.04 amd64, upgrade/rollback descartável, imagens broker/admin legado por digest, tag, prerelease e oito hashes remotos serão vinculados no [registro P209](../../prompts/registros/P209-release-0.38.0.md) após validação. O WSL instalado do operador não será alterado. Ubuntu 24.04, arm64, Windows nativo e fases globais 6A–6D/7–9 continuam abertos.
