# XMQR broker/admin legado 0.40.0 — WSS mTLS local (candidato)

P212 adiciona `MQTT_WSS_BIND` ou `broker.wss_bind` somente no modo `secure-mtls`, em IP loopback e porta própria. O upgrade WSS exige `/mqtt` e subprotocolo `mqtt`; `Origin` é recusado. O certificado cliente verificado, usuário/senha e ACL usam a política do TCP mTLS. TCP/WSS compartilham router, estado, quota e rotação TLS. MQTT 3.1.1/5 pub/sub e cruzamento TCP/WSS foram validados com o client C114.

**Estado e rollback:** documento durável v15 sem migração. Broker 0.39.0 e admin independente 0.10.0 leem v15; preserve backup privado antes de downgrade. A 0.39.0 não contém WSS. Client 0.33.0 é o candidato correspondente, mas cada release é independente.

**Distribuição:** P213 exige CI da fonte candidata exata, pacote Ubuntu 26.04 amd64, upgrade/rollback descartável, imagens broker/admin por digest remoto, tag e prerelease com oito anexos e SHA-256 remoto. Registrar resultados antes de declarar este candidato publicado. O WSL instalado do operador não é alterado. WSS remoto, navegador, TLS-senha por WSS, Ubuntu 24.04, arm64, Windows nativo e fases globais 6A–6D/7–9 seguem abertos.
