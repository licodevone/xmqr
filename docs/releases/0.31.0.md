# XMQR broker 0.31.0 — motivos MQTT 5 e interoperabilidade (experimental)

P168 amplia a interoperabilidade selecionada com Eclipse Paho Python 2.1.0, além de Mosquitto. P169/P170 aceitam PUBACK/PUBREC negativos válidos do assinante, encerrando a tentativa sem perder a conexão. P171 aceita `0x92` e propriedades diagnósticas de PUBREL/PUBCOMP. P172 aceita DISCONNECT `0x04` para publicar o Will pela transição durável, inclusive atraso/restart; `0x00` continua cancelando o Will.

**Estado e rollback:** o documento permanece v15, sem migração. Broker 0.30.0 e admin independente 0.10.0 leem v15; preservar backup privado antes de downgrade. Para voltar a broker 0.28.0, é necessário backup v14 anterior à migração. Client independente 0.27.0 permanece parceiro. Fases 6A–6D e 7–9 ainda abertas.

**Distribuição:** candidato a pacote Ubuntu 26.04 amd64, imagens numeradas broker/admin legado, tag anotada e prerelease após gates do commit exato, ciclo descartável de upgrade/rollback e conferência de hashes remotos. WSL do operador e Docker `latest` não serão alterados. Ubuntu 24.04, arm64 e Windows nativo ainda não homologados.
