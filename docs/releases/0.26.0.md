# XMQR broker 0.26.0 — shared subscriptions MQTT 5 (experimental)

P153/P154 acrescentam `$share/{grupo}/{filtro}` MQTT 5. O broker distribui cada publicação a um membro por grupo/filtro e entrega cópia separada a assinantes normais, sem retained inicial no grupo. Sessões persistentes guardam a associação no estado v13; QoS1/2 pode ser atribuído a membro offline se não houver ativo, e uma entrega QoS2 iniciada continua com a sessão escolhida após reconexão. O client independente 0.24.0/C89 é o parceiro planejado. A recomendação de redistribuir QoS1 após término da sessão, AUTH, demais lacunas MQTT 5 e fases 7–9 seguem pendentes.

**Estado e rollback:** a primeira gravação migra v12 para v13. Antes de iniciar, pare o broker e preserve backup offline privado v12. Broker 0.25.0 e admin independente 0.7.0 não abrem v13. Para voltar a 0.25.0, pare o broker, restaure o backup v12 verificado e instale o pacote anterior; downgrade de pacote sozinho não converte estado.

**Distribuição:** CI do commit de versão, admin A16, pacote Ubuntu 26.04 amd64, imagens numeradas e anexos remotos estão pendentes. O processo não instalará no WSL do operador nem moverá Docker `latest`.
