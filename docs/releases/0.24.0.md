# XMQR broker 0.24.0 — opções de assinatura MQTT 5 (experimental)

P146 protege a retomada QoS2 com quota durável cheia: um novo packet ID recebe PUBREC `0x97`, mantendo a transação antiga. P147 implementa Retain Handling 0/1/2 por filtro. P148 implementa No Local e Retain As Published por filtro, inclusive filtros sobrepostos e retomada após reinício; o `mqtt-admin` legado acompanha a versão. O client 0.22.0 é o parceiro planejado para os novos bits de assinatura.

**Estado e rollback:** o documento durável passa de v10 a v11 na próxima gravação. Antes de iniciar o broker novo, pare o serviço e preserve backup offline privado v10. Broker 0.23.0 e admin independente 0.5.0 não abrem v11. Para voltar a 0.23.0, pare o broker, restaure o backup v10 verificado e só então instale a versão anterior; o ciclo de downgrade do `.deb` não converte o estado. A14 atualizará o admin independente para v11 em marco separado. Confira manifesto e SHA-256 antes de instalar; o processo de release não altera a WSL do operador.

**Limites:** Subscription Identifier, compartilhamento, AUTH, WebSocket, bridge e Windows nativo seguem abertos. O `mosquitto_sub` 2.0.22 não foi homologado para Topic Alias de saída abreviado; esta direção continua limitada. Não se declara conformidade MQTT 5 integral. Docker `latest` fica intacta.

Publicação somente após CI, pacotes/imagens e ciclo de instalação aceitos. Evidências: [P146](../../prompts/registros/P146-qos2-resume-quota-mqtt5.md), [P147](../../prompts/registros/P147-retain-handling-mqtt5.md), [P148](../../prompts/registros/P148-no-local-retain-as-published-mqtt5.md).
