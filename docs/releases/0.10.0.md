# XMQR Broker 0.10.0 — experimental

Integração com systemd e instalação por pacote Ubuntu26.04 amd64.

- SIGTERM/SIGINT coordenam fechamento do listener, Wills duráveis, preservação
  de sessões persistentes/QoS2, snapshot e encerramento do writer.
- Unit xmqr-broker.service com usuário dedicado, estado privado e reinícios
  limitados. Reload via SIGHUP só para bundle de segurança dinâmica.
- Pacote deb instalável pelo apt; instalação não habilita/inicia o serviço.
  Upgrade/remove preservam configuração/dados; credenciais são externas.
- Documentação e CI atualizados; binários mqtt-broker e mqtt-admin preservados.

Validação:83 testesRust,3 integrações shutdown,9 regressõesWill,4 cenários
externos com clientes Mosquitto; fmt/Clippy/build/inventário aprovados.
Systemctl no Ubuntu26/WSL:pub/sub mTLS,reload,restart,stop aprovados com units
isoladas e usuário não root. Instalação/upgrade/remove/purge validados em
container Ubuntu26 limpo, preservando dados. Windows:compilação verificada.

Baixe o deb e o checksum juntos, verifique com `sha256sum -c`, depois:

```sh
sudo apt install ./xmqr-broker_0.10.0-1_amd64.deb
```

Configure certificados/bundle em /etc/xmqr antes de ativar pelo systemctl.
Guia completo:docs/ubuntu-systemd.md. Upgrade deixa serviço parado até start
explícito. APT próprio assinado ainda não disponível; use arquivo local.

Experimental:sem promessa de produção, Ubuntu24/arm64 ou MSRV1.88 exato.
Mosquitto externo validado em open-lab, não mTLS externo completo. Sem
sd_notify/Watchdog. Pacote/binaries compilados em Ubuntu26 com Rust1.99.
