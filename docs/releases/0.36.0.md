# XMQR broker 0.36.0 — diagnóstico MQTT 5 adicional (experimental)

P199 classifica CONNECT inicial cujo bloco de propriedades é íntegro mas campos posteriores estão truncados ou excedentes: CONNACK `0x81` quando Maximum Packet Size permite, sem criar sessão ou Will. P200 classifica flags reservadas inválidas de SUBSCRIBE, UNSUBSCRIBE e PUBREL após CONNACK com DISCONNECT `0x81` antes de aplicar estado. P201 classifica CONNACK, SUBACK, UNSUBACK e PINGRESP exclusivos do servidor enviados pelo client com DISCONNECT `0x82` antes de interpretar o corpo. MQTT 3.1.1 mantém o comportamento anterior nos casos descritos; a matriz MQTT 5 integral continua aberta.

**Estado e rollback:** documento v15 sem migração. Broker 0.35.0 e admin independente 0.10.0 continuam capazes de ler v15; preserve backup privado antes de downgrade. Broker 0.28.0 ou anterior requer backup v14 anterior à migração. O client independente 0.30.0 permanece. Esta versão não é homologação de produção.

**Distribuição candidata:** fonte e CI, pacote Ubuntu 26.04 amd64, upgrade/rollback descartável, imagens broker/admin legado por digest e hashes remotos serão vinculados no [registro P202](../../prompts/registros/P202-release-0.36.0.md) após validação. O WSL instalado do operador não será alterado. Ubuntu 24.04, arm64, Windows nativo e fases globais 6A–6D/7–9 continuam abertos.
