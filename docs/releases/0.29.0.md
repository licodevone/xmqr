# XMQR broker 0.29.0 — Will MQTT 5 e estado v15 (experimental)

P162 permite limitar Keep Alive MQTT 5 e anuncia Server Keep Alive quando reduz o valor pedido. P163 preserva Payload Format Indicator, Content Type, Response Topic, Correlation Data e User Property ordenada no Will. P164 acrescenta Message Expiry Interval: o intervalo fica no Will pendente e só se torna deadline absoluto quando ele é publicado, inclusive após atraso, reinício e término de sessão. Client 0.26.0/C94–C95 é o par validado. MQTT 5 integral e fases 6A–6D permanecem abertas.

**Estado e rollback:** primeira gravação migra o documento de v14 para v15. Broker 0.28.0 rejeita v15; admin 0.9.0 consegue transportar backup bruto, mas o par suportado é admin independente 0.10.0/A19. Preserve backup offline privado v14 verificado antes do upgrade. Para voltar ao broker 0.28.0, restaure esse backup com o serviço parado. Arquivos privados não devem ser sobrescritos pelo pacote.

**Distribuição:** publicar tag anotada, prerelease, pacote Ubuntu 26.04 amd64, imagens numeradas e manifestos após CI do commit exato e ensaio descartável de upgrade/rollback. O [registro P165](../../prompts/registros/P165-release-0.29.0.md) documentará hashes/digests. WSL do operador e Docker `latest` não são alterados.
