# Broker e admin legado 0.44.0 — candidato experimental

## Novidades

- [P268](../../prompts/broker/268-listener-protocol-versions.md) permite
  definir as versões MQTT aceitas em cada endereço TCP, WS ou WSS.
  Sem política explícita, o listener aceita MQTT 3.1.1 e MQTT 5.
- [P265](../../prompts/broker/265-check-config.md) adiciona
  `mqtt-broker --check-config` para validação antes da inicialização.
- [P267](../../prompts/broker/267-bounded-tls-material.md) limita a leitura
  de arquivos PEM e reaproveita as CAs decodificadas.
- [P271](../../prompts/broker/271-500-conexoes-mqtt.md) amplia as quotas
  configuráveis de conexões e sessões para 500. A fonte
  [P274](../../prompts/broker/274-1000-conexoes-mqtt.md) amplia o teto
  para 1.000. O padrão permanece 64.
- [P272](../../prompts/broker/272-aceite-integrado-500.md) prepara o ensaio
  de Client e Admin com o Broker no limite. O ensaio TCP em Ubuntu e a
  medição de carga sustentada estão pendentes.

Exemplo para um listener já configurado em `127.0.0.1:8883` aceitar MQTT 5:

```toml
[[listener_protocols]]
bind = "127.0.0.1:8883"
accept_protocol_versions = [5]
```

Veja o [guia de configuração](../architecture/configuration.md) para
regras de bind, valores aceitos e validação.

Para habilitar as quotas ampliadas, configure as duas chaves no TOML:

```toml
[limits]
max_connections = 1000
max_sessions = 1000
```

Sessões persistentes desconectadas contam na segunda quota. Veja o
[orçamento de conexões e o ensaio de integração](../capacity-500.md).

## Atualização e retorno à versão anterior

O formato persistente permanece v16. Antes de atualizar, guarde uma cópia
privada da configuração e do estado, incluindo o marcador de perfil.
Para voltar à versão 0.43.0, use a configuração compatível com ela, sem
`[[listener_protocols]]` e com quotas de até 64 conexões e sessões. Se
o estado atual exceder a quota antiga, restaure um backup compatível em
outro diretório com o serviço parado. O ciclo de pacote e rollback precisa
passar em ambiente descartável antes da distribuição.
