# XMQR broker 0.33.0 — propriedades de assinatura MQTT 5 (experimental)

P180 aceita User Property repetível em SUBSCRIBE e UNSUBSCRIBE MQTT 5, inclusive junto de Subscription Identifier. Limita cada pacote a 16 pares/2048 bytes codificados e cada campo a 256 bytes. O broker recusa propriedades inválidas antes de mudar a assinatura e não persiste os pares. P181 envia DISCONNECT `0x81` após CONNACK para identificador de propriedade fora de contexto e `0x82` para Subscription Identifier duplicado. Os testes cobrem Will, sessão durável, MQTT 3.1.1 e regressões P175–P180. A matriz normativa completa continua aberta.

**Estado e rollback:** documento v15, sem migração. Broker 0.32.0 e admin independente 0.10.0 ainda leem v15; preserve backup privado antes do downgrade. Para voltar a broker 0.28.0 ou anterior, requer-se backup v14 anterior à migração. Client C102 será distribuído de forma independente.

**Distribuição:** candidato experimental. Publicação de tag/prerelease depende de CI da fonte exata, pacote Ubuntu 26.04 amd64, upgrade/rollback em container descartável, imagens numeradas por digest e SHA-256/tamanhos remotos. WSL do operador e Docker `latest` ficam fora do ensaio. Ubuntu 24.04, arm64 e Windows nativo ainda não estão homologados.
