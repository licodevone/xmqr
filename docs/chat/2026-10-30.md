**Passo 3 — Escreva o primeiro servidor**

Abra `src/main.rs`, apague o conteúdo inicial e digite:

```rust
use std::io;

use tokio::net::TcpListener;

#[tokio::main]
async fn main() -> io::Result<()> {
    let address = "127.0.0.1:18883";
    let listener = TcpListener::bind(address).await?;

    println!("XMQR iniciado em {address}");
    println!("Pressione Ctrl+C para encerrar.");

    loop {
        tokio::select! {
            connection = listener.accept() => {
                let (socket, peer) = connection?;

                println!("Conexão recebida de {peer}");

                drop(socket);
            }

            result = tokio::signal::ctrl_c() => {
                result?;

                println!("Encerrando XMQR...");
                break;
            }
        }
    }

    Ok(())
}
```

Esse código:

- Abre uma porta TCP acessível apenas pelo próprio computador.
- Aguarda uma conexão ou o comando Ctrl+C.
- Mostra o endereço de quem conectou.
- Fecha a conexão recebida e continua aguardando outras.
- Encerra o programa quando você pressiona Ctrl+C.

A porta `18883` será nossa porta de laboratório.
