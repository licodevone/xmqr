# Originais preservados

broker/ e clients/ são cópias byte a byte dos prompts de origem. README.md e
00-sequencia-mestra.md são catálogos de contexto do projeto consumidor; seus
links a outras trilhas não foram importados. Estes catálogos são arquivo histórico,
não sequência executável do XMQR. Não executar arquivos de origem diretamente.
manifesto.json registra caminhos de origem, cópias e SHA-256 no momento da importação.
Não há prova de que estes prompts produziram os commits do XMQR.
As cópias da raiz prompts/broker e prompts/clients são a versão adaptada.
Nenhum arquivo original do projeto consumidor foi alterado.
