# P-DOC-02 — Configurar instruções, skills e agentes do XMQR

Versão 1.0. Tipo: configuração documental solicitada pelo mantenedor.

## Prompt de trabalho

Confirme D:\projects\my-project\xmqr e preserve trabalho existente. Leia os
prompts atuais, CONTRIBUTING, VERSIONING e código relevante. Consulte skill-creator,
documentação oficial e runtime local antes de escolher formatos.
Crie AGENTS.md como instruções do repositório e skills próprias em .agents/skills
para implementação Rust/MQTT, testes e revisão de segurança. Configure agentes
especializados no formato de projeto suportado (.codex/agents/*.toml), distinguindo
arquivo reconhecível de agente efetivamente carregado/acionado. Não transplante
agentes, skills ou MCPs de outro projeto. Não altere modelo, permissões, trust,
credenciais ou configuração global. Não faça instalação, commit ou publicação.
Alinhe índice, contrato e orquestrador ao fluxo prompts-primeiro e ao código real.
Preserve todos os prompts de clientes e todos os originais. Valide estrutura,
TOML, frontmatter, links, caminhos, comandos existentes e escopo das alterações.
Não implemente funcionalidades MQTT nem execute testes funcionais/serviços nesta tarefa.

## Aceite

Arquivos de orientação/configuração coerentes, três skills válidas, agentes no
formato oficial, nenhuma mudança de código funcional ou de originais. Informar
limitações de carregamento nesta sessão e como iniciar nova sessão no projeto.
Resultado em registros/P-DOC-02-configuracao.md e VALIDACAO-CONFIGURACAO.json.
