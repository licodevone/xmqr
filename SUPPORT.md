# Suporte

XMQR é experimental e mantido pela comunidade.

- Consulte primeiro o [README](README.md) e a pasta [docs](docs).
- Para dúvida de uso reproduzível, abra uma
  [GitHub Discussion](https://github.com/licodevone/xmqr/discussions) quando esse
  recurso estiver habilitado; caso contrário, use uma issue.
- Para defeitos, use o
  [formulário de bug](https://github.com/licodevone/xmqr/issues/new?template=bug_report.yml)
  e inclua versão, sistema operacional, logs sanitizados e passos mínimos.
- Para propostas, use o
  [formulário de funcionalidade](https://github.com/licodevone/xmqr/issues/new?template=feature_request.yml)
  e descreva a cláusula MQTT ou o caso de uso.
- Para vulnerabilidades, siga [SECURITY.md](SECURITY.md) e não publique detalhes
  antes da correção.

Não há SLA de suporte. Nunca publique certificados privados, senhas, hashes de
usuários reais, arquivos de estado ou payloads sensíveis.
